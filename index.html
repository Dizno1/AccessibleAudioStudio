Keyboard Shortcuts
  • Ctrl+Alt+R — Start or Stop Recording (toggle, like the record button on a physical recorder)
  • Ctrl+Alt+Space — Pause or Resume Recording
  • Ctrl+Alt+P — Play or Pause the selected recording
  • Ctrl+O — Open Audio
  • Ctrl+N — New Audio

Each Audio Editor window has its own Save, Save As, Cut, Copy, Paste, Undo, and Redo shortcuts — see that window's own Keyboard Shortcuts disclosure.

Shortcuts do not work while typing in a text field, and every visible button always works as an alternative.
